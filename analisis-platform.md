Aspek Web Desktop Mobile
Bahasa utama HTML, CSS, JavaScript/TypeScript di sisi klien; di sisi server dapat memakai JavaScript (Node.js), PHP, Python, Java, dll. C#, C++, Java, Python; atau JavaScript lewat framework seperti Electron Kotlin dan Java (Android), Swift (iOS); lintas platform dengan Dart (Flutter) atau JavaScript (React Native)
Arsitektur Client-server: peramban sebagai klien, server menyediakan halaman dan API; umumnya dipisah menjadi frontend dan backend Aplikasi berdiri sendiri (standalone) yang berjalan langsung di OS dan mengakses sumber daya lokal seperti file dan perangkat keras; dapat juga terhubung ke server Aplikasi native di atas SDK sistem operasi (Android/iOS), sering terhubung ke backend melalui API; mengikuti siklus hidup aplikasi yang diatur OS
Cara distribusi Dideploy ke server atau hosting lalu diakses lewat URL, tanpa instalasi File installer (.exe, .msi, .dmg, .deb) diunduh dari situs atau toko aplikasi seperti Microsoft Store Toko aplikasi resmi (Google Play Store, Apple App Store) atau berkas APK untuk sideload di Android
Keunggulan Lintas platform lewat peramban, tidak perlu instalasi, pembaruan langsung dari server, mudah dijangkau Performa tinggi, akses penuh ke sumber daya perangkat, dapat berjalan offline, cocok untuk pekerjaan berat Akses sensor (kamera, GPS, akselerometer), notifikasi push, portabel, pengalaman sentuh yang sesuai perangkat
Keterbatasan Bergantung pada koneksi internet dan kemampuan peramban, akses perangkat keras terbatas, performa di bawah aplikasi native Harus diinstal dan diperbarui per perangkat, bergantung pada sistem operasi, distribusi lebih rumit Layar kecil, baterai dan sumber daya terbatas, proses review toko aplikasi, fragmentasi perangkat (terutama Android)
Contoh aplikasi Google Docs, Tokopedia (versi web), GitHub Visual Studio Code, Microsoft Word, Adobe Photoshop WhatsApp, Gojek, Instagram
